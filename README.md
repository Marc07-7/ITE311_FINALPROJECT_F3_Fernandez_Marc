# Naujan Lake Eco-Tourism and Wildlife Information Management System Using Ghost Content Management System

**Student Name:** Fernandez, Marc Stephen L.

**Course and Section:** Web System and Technologies 2 (ITE311) - BSIT III-F3

## Project Description

The proposed system can generate income through eco-tourism packages, promotional listings for local tourism businesses, membership subscriptions, and partnerships with tour guides and local establishments. The platform may also provide paid promotional features for accredited resorts, restaurants, tour operators, and other tourism-related businesses. These revenue sources can help support the maintenance, hosting, content management, and future development of the system while promoting Naujan Lake as an eco-tourism destination.

## Features

- Wildlife information directory with category and conservation status filters
- Eco-tourism package management with pricing and featured packages
- Local business listings (resorts, restaurants, tour operators, guides) with accreditation and promotion tiers

## Technologies Used

- PHP 8
- HTML5 and CSS3
- JSON file storage
- Laragon / XAMPP (local server)
- Git and GitHub

## How to Run

1. Place this folder inside C:/laragon/www/ (or htdocs for XAMPP).
2. Start Apache.
3. Open http://localhost/NaujanLake-EcoTourism in your browser.
